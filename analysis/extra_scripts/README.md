# extra_scripts: provenance for the report's [tmp] numbers

The research report (`docs/Liver_Tumor_Research_Report.pdf`, section 8.5) tags some numbers `[tmp]`: they were produced by
ad hoc analysis scripts rather than by the maintained code. These are those scripts and their small outputs, kept as provenance
only. They are not cleaned up, not maintained, and not guaranteed to run as they are: they were written for one analysis session
against the local LiTS data. Absolute paths were replaced by `.` (the repository root of the original machine) and `~`.
